HOW MALICIOUS EXTENSIONS CAN HARM USERS:

- Steal passwords and sensitive data
- Track browsing activity
- Inject malicious ads
- Redirect users to fake websites
- Download malware in background

------------------------------------------------------------

SAFE PRACTICES FOR USING BROWSER EXTENSIONS:

- Install extensions only from official stores
- Check permissions carefully before installing
- Read user reviews and ratings
- Remove unused extensions regularly
- Keep extensions updated
- Avoid extensions with excessive permissions

------------------------------------------------------------

INTERVIEW QUESTIONS AND ANSWERS:

1. How can browser extensions pose security risks?
They can access sensitive data, track activity, inject ads, or steal credentials.

2. What permissions should raise suspicion?
Access to all websites, browsing history, passwords, and background data.

3. How to safely install browser extensions?
Install only from official stores and check reviews and permissions.

4. What is extension sandboxing?
It is a security mechanism that isolates extensions from critical browser processes.

5. Can extensions steal passwords?
Yes, malicious extensions can capture keystrokes or access stored credentials.

6. How to update extensions securely?
Enable automatic updates from the official browser store.

7. Difference between extensions and plugins?
Extensions enhance browser features, while plugins handle specific content types.

8. How to report malicious extensions?
Report directly through the browser’s extension store or security reporting tools.
