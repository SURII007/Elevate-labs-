PROTOCOLS IDENTIFIED IN CAPTURE:

1. TCP (Transmission Control Protocol)
TCP packets were observed establishing reliable connections between the local
machine and web servers. TCP ensures ordered and error-free data transmission.

------------------------------------------------------------

2. UDP (User Datagram Protocol)
UDP packets were observed mainly in DNS queries. UDP is connectionless and faster
but does not guarantee delivery.

------------------------------------------------------------

3. DNS (Domain Name System)
DNS query packets were captured when resolving domain names into IP addresses.
Example: Query for "google.com".

------------------------------------------------------------

4. HTTP / HTTPS
HTTP and HTTPS traffic was observed during website browsing. HTTPS traffic was
encrypted, while HTTP packets showed readable request headers.

------------------------------------------------------------

These filters helped isolate and analyze specific protocol traffic efficiently.

INTERVIEW QUESTIONS AND ANSWERS:

1. What is Wireshark used for?
Wireshark is a network packet analyzer used to capture and analyze network traffic
in real time.

2. What is a packet?
A packet is a small unit of data transmitted over a network.

3. How to filter packets in Wireshark?
By using display filters such as tcp, udp, dns, http in the filter bar.

4. What is the difference between TCP and UDP?
TCP is reliable and connection-oriented, while UDP is faster and connectionless.

5. What is a DNS query packet?
It is a request sent to a DNS server to resolve a domain name into an IP address.

6. How can packet capture help in troubleshooting?
It helps identify network issues, delays, dropped packets, and misconfigurations.

7. What is a protocol?
A protocol is a set of rules that define how data is transmitted over a network.

8. Can Wireshark decrypt encrypted traffic?
Wireshark cannot decrypt encrypted traffic unless encryption keys are provided.
